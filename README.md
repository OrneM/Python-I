# Curso de Python 🐍📚

Repositorio con ejercicios, prácticas y mini-proyectos realizados durante el **curso de Python**.
Aquí encontrarás desde conceptos básicos de lógica de programación hasta aplicaciones modulares y con interfaz gráfica de escritorio.

---

## 📂 Contenido del Proyecto

Este repositorio contiene la evolución clase a clase y proyectos prácticos de integración.

### 🔹 1. Calculadora Modular (`Modulos/`)
Un proyecto de consola que aplica el concepto de **modularización** separando la lógica en archivos distintos.
- **`programa.py`**: Script principal que ejecuta el menú interactivo.
- **`operaciones.py`**: Módulo con funciones aritméticas (suma, resta, multiplicación, división).
- **`areas.py`**: Módulo para cálculo de áreas geométricas (círculo, cuadrado, rectángulo).

**Para ejecutarlo:**
```bash
python Modulos/programa.py
```

### 🔹 2. Aplicaciones de Escritorio con Tkinter
Introducción a interfaces gráficas (GUI) nativas de Python.
- **`clase9.py`**: Primera aplicación con ventana, input de texto y botón de saludo interactivo.
- **`clase9-1.py`**: **Calculadora Gráfica**. Permite ingresar dos números y realizar sumas o restas visualizando el resultado en pantalla. Incluye botón de salida.

**Para ejecutar la calculadora gráfica:**
```bash
python clase9-1.py
```

### 🔹 3. Ejercicios Fundamentales (`clase1.py` - `clase8.py`)
Scripts progresivos donde se practican los pilares del lenguaje:
- **Funciones:** Definición, pŕametros y retorno (`clase8.py`).
- **Estructuras de Control:** Condicionales y Bucles.
- **Tipos de Datos:** Listas, tuplas, diccionarios y operaciones básicas.

- [x] **Lógica de Programación:** Estructura de programas y algoritmos básicos.
