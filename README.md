# Curso de Python 🐍📚

Repositorio con ejercicios, prácticas y mini-proyectos realizados durante el **curso de Python**.  
La idea es llevar un registro ordenado de lo aprendido, con ejemplos claros y código modular.

---

## 🎯 Objetivos

- Entender la lógica de programación y la estructura de un programa.
- Aprender los fundamentos del lenguaje Python (tipos, operaciones, entradas/salidas).
- Practicar condicionales, bucles y estructuras de datos (listas,.I, tuplas, diccionarios).
- Trabajar con funciones, módulos y modularización.
- Crear aplicaciones de escritorio simples con **tkinter**.
- Usar IA como apoyo para depuración, optimización y mejoras de UX (cuando aplique).

---

## 🧩 Contenidos del curso (según temario)

### 1) Introducción, conceptos y entrada de datos
- Programación y estructura de un programa
- Preparación del entorno
- IDE vs editor de código y herramientas
- Fundamentos del lenguaje
- Tipos de datos
- Operaciones básicas
- Carga de datos (`input`)
- Conversión entre tipos de datos
- Solución de errores con IA

### 2) Condicionales, bucles y listas
- Condicionales
- Listas: concepto y propósito
- Bucle `while`
- Bucle `for`
- `range`
- Matrices con listas
- Colecciones: tuplas y diccionarios
- Optimización de código con IA

### 3) Módulos y funciones
- Modularización
- Bibliotecas y librería estándar
- Sintaxis para incorporar módulos
- Scripts con varios módulos
- Funciones: conceptos básicos
- Alcance de variables (local y global)
- Argumentos y retorno

### 4) Aplicaciones de escritorio
- Módulo `tkinter`
- Funcionamiento de tkinter (clases y objetos)
- Widgets (componentes)
- Primera aplicación
- Buenas prácticas de UX con IA
